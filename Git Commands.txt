Create / Clone Repos

| Action            | Command           |
| ----------------- | ----------------- |
| Init new repo     | `git init`        |
| Clone remote repo | `git clone <url>` |

Staging & Committing

| Action            | Command                   |
| ----------------- | ------------------------- |
| Check status      | `git status`              |
| Add one file      | `git add file.txt`        |
| Add all files     | `git add .`               |
| Commit            | `git commit -m "message"` |
| Amend last commit | `git commit --amend`      |

Branching

| Action          | Command                     |
| --------------- | --------------------------- |
| List branches   | `git branch`                |
| Create branch   | `git branch dev`            |
| Switch branch   | `git checkout dev`          |
| Create + switch | `git checkout -b feature-x` |
| Delete branch   | `git branch -d dev`         |

Pull / Push / Remote

| Action                 | Command                       |
| ---------------------- | ----------------------------- |
| Add remote             | `git remote add origin <url>` |
| Check remotes          | `git remote -v`               |
| Push branch first time | `git push -u origin main`     |
| Push updates           | `git push`                    |
| Pull updates           | `git pull`                    |

Merge & Rebase

| Action                     | Command              |
| -------------------------- | -------------------- |
| Merge branch into current  | `git merge dev`      |
| Rebase current onto branch | `git rebase main`    |
| Abort rebase               | `git rebase --abort` |

Logs & History

| Action                   | Command             |
| ------------------------ | ------------------- |
| Full commit log          | `git log`           |
| One-line log             | `git log --oneline` |
| Show file changes        | `git diff`          |
| Show last commit details | `git show`          |

Undo / Reset

| Action                            | Command                         |
| --------------------------------- | ------------------------------- |
| Unstage a file                    | `git restore --staged file.txt` |
| Discard local file changes        | `git restore file.txt`          |
| Reset to previous commit (soft)   | `git reset --soft HEAD~1`       |
| Reset & discard changes (hard) ⚠️ | `git reset --hard HEAD~1`       |

Stashing

| Action       | Command           |
| ------------ | ----------------- |
| Save changes | `git stash`       |
| List stashes | `git stash list`  |
| Apply stash  | `git stash apply` |
| Drop stash   | `git stash drop`  |
